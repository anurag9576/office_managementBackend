# Office Management System Backend

A RESTful API for an Office Management System built with Node.js, Express, Mongoose, and MongoDB.

## Features
- JWT Authentication
- Role-based Access Control (Admin, Employee, HR, Manager)
- Employee Management
- Department Management
- Attendance Tracking
- Leave Management
- Announcements & Interaction

## Tech Stack
- Node.js
- Express
- MongoDB (via Mongoose)
- bcryptjs
- jsonwebtoken

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Create a `.env` file with `PORT`, `MONGO_URI`, and `JWT_SECRET`.
4. Run the seed script: `npm run seed`.
5. Start development server: `npm run dev`.
